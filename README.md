# KWin Compose

Прототип композиции перекрывающихся окон для KDE Plasma 6 на Arch Linux.
Окна сохраняют индивидуальные размеры; положение и размер привязываются к динамической сетке.

## Быстрый запуск песочницы

Нужен Node.js 20 или новее.

```sh
npm ci
npm run dev
```

Открыть <http://127.0.0.1:5173>. Песочница использует модули из `src/` напрямую.
Можно добавлять окна разных размеров, форматировать сцену, перетаскивать окна за заголовок,
менять размер за нижний правый угол, скрывать сетку и выбирать пропорции области.
Смена пропорций загружает новый пример и отключает авторазмещение.

## Сборка и проверки

```sh
npm test
npm run check
npm run build
```

Результат: `dist/kwin-compose.kwinscript`, распакованный пакет — `package/`.
Зависимостей во время работы KWin-скрипта нет. Biome установлен только как зависимость разработки.
Сборка объединяет пять модулей в один файл; алгоритм в песочнице не дублируется.

```sh
npm run format        # Biome: JS/JSON/CSS
npm run format:check  # проверка оформления без изменений
```

Для редакторов добавлены `biome.json`, `.prettierrc.json` и `.editorconfig`.
Prettier в зависимости проекта не входит: конфиг оставлен для запуска из IDE, в том числе для HTML/Markdown.
Не запускайте два форматтера последовательно на одном JS-файле: основной форматтер кода — Biome.
QML-проверки оформлены через Qt `qmlformat`; сгенерированный код пересобирается из исходников.

## Установка в KDE — вручную

Из корня проекта:

```sh
kpackagetool6 --type KWin/Script --install dist/kwin-compose.kwinscript
```

В **Параметры системы → Управление окнами → Сценарии KWin** включить **Compose** и применить.
При обновлении уже установленного пакета:

```sh
kpackagetool6 --type KWin/Script --upgrade dist/kwin-compose.kwinscript
```

После обновления выключить и снова включить сценарий, применяя изменения на каждом шаге.

Хоткей по умолчанию: **Meta+Ctrl+F**, действие **«Форматировать окна»**.
Его можно изменить в системных настройках комбинаций клавиш, найдя это действие.
Если комбинация занята, назначьте свободную.

До первого нажатия геометрия окон не меняется. Хоткей форматирует текущие монитор и стол,
включает для них размещение новых окон и сбрасывает цикл из шести опор.
Повторное нажатие форматирует эту область заново. Закрытие окна не откатывает счётчик.
Режим хранится только в памяти и сбрасывается при перезагрузке сценария.

## Настройки

Значения читаются из группы `[Script-kwin-compose]` файла `kwinrc`:

| Ключ           | По умолчанию | Значение                                                   |
| -------------- | ------------ | ---------------------------------------------------------- |
| `DesiredStep`  | `30`         | Желаемый шаг в логических единицах; минимум 8              |
| `MarginLeft`   | `1`          | Отступ слева в ячейках                                     |
| `MarginRight`  | `1`          | Отступ справа в ячейках                                    |
| `MarginTop`    | `1`          | Отступ сверху в ячейках                                    |
| `MarginBottom` | `2`          | Отступ снизу в ячейках                                     |
| `GapCells`     | `1`          | Минимальный зазор непересекающихся окон по разделяющей оси |

Пример изменения шага:

```sh
kwriteconfig6 --file kwinrc --group Script-kwin-compose --key DesiredStep 30
```

После изменения настроек выключить и снова включить сценарий.
Рабочая область запрашивается у KWin через `MaximizeArea`; размер панели повторно не вычитается.
Отступы резервируются внутри этой области.

## Отключение и удаление

Снять флажок **Compose** в списке сценариев KWin и применить. Окна останутся на своих местах.
Затем при необходимости удалить пакет:

```sh
kpackagetool6 --type KWin/Script --remove kwin-compose
```

Скрипт не предоставляет отмену раскладки. При отключении и удалении исходные позиции не восстанавливаются.

## Устройство и принятые решения

- `src/grid.js` — сетка, отступы, округление размеров и ограничения.
- `src/geometry.js` — пересечения, вычитание прямоугольников и совокупная видимость.
- `src/placement.js` — шесть опор, перебор позиций и топологический порядок сцены.
- `src/kwin-adapter.js` — события KWin, принадлежность области, ограничения и применение геометрии.
- `src/main.js` — активация областей, очередь операций и защита от повторной обработки.

Поиск идёт по манхэттенскому расстоянию от опоры в единицах сетки. При равенстве:
вертикальное расстояние, координата Y, координата X. Для второго перекрывающегося окна
сначала проверяется правая позиция на одну строку ниже верхнего края.
Размер во время поиска фиксирован. Нижние и правые опоры привязывают соответствующие края.
Разница округления границ допускается в пределах одной логической единицы.

При полном форматировании ещё не обработанные окна остаются препятствиями на исходных местах.
Это консервативный подход: он иногда отвергает возможную общую перестановку, зато отказ от
перемещения одного окна не делает уже выбранные положения несогласованными.
Следующий шаг в KWin читает фактическую сцену после применения предыдущего.

Окно, у которого была видимая площадь, не должно полностью исчезнуть под совокупностью верхних
окон. Узкие полосы проверяются отдельно, попарно. Уже полностью скрытые окна не обязаны стать
видимыми. Прозрачность, тени и непрямоугольные формы не моделируются.

Исключены также частично максимизированные окна. Диалоги остаются неподвижными препятствиями.
Окна на всех столах учитываются на текущем столе; список Activities фильтруется по текущей
активности, но она не входит в ключ режима. Неудачная попытка для подходящего окна занимает
позицию цикла; исключённое окно — нет.

## Что проверено и что ещё требует KDE-сессии

Проверено: 28 тестов геометрии, сетки, размещения и координатора с имитацией сигналов;
выполнение общего кода в Qt 6.11.2; браузерная песочница в Qt WebEngine, включая перетаскивание.
В окружении обнаружен KWin 6.7.4. **Пакет в рабочую сессию не устанавливался и не загружался.**

Ограничения прототипа:

- `windowAdded` не считается гарантией окончательного размера. Сценарий ждёт 80 мс без изменений
  геометрии, но не более 1500 мс. Это ограниченное ожидание по событиям, а не постоянный опрос.
- После записи геометрии ожидание ограничено 500 мс. Если приложение отклонило размер,
  разрешена одна попытка размещения с фактическим размером, затем одна попытка вернуть исходную
  геометрию. Поздние ответы приложения могут изменить итог; бесконечных исправлений нет.
- Ручное перемещение/изменение размера прекращает коррекцию. Изменённое пользователем окно,
  ещё ожидающее полного форматирования, пропускается.
- Скрипт не активирует и не поднимает окна намеренно. Восстановление свёрнутого окна самим KWin
  может поменять стек или фокус; точное сохранение в таком случае не гарантируется.
- Для безопасного исключения максимизации нужен читаемый `maximizeMode`. Если API не отдаёт
  числовой режим, окно пропускается. Совместимость со всеми ранними выпусками Plasma 6 не заявлена.
- Анимация открытия, отсутствие скачков, реальные ограничения Wayland/XWayland и зазор до
  плавающей панели требуют проверки в KDE. Песочница их не воспроизводит.

Краткий ручной сценарий после установки: проверить отсутствие вмешательства до хоткея;
отформатировать 2–6 окон; вручную сдвинуть одно и открыть новое; повторить на другом столе и
мониторе; проверить свёрнутые, максимизированные, полноэкранные окна и диалоги;
проверить плавающую панель и фокус. При проблемах отключить сценарий.

Дополнительные проверки Qt на Arch Linux (без загрузки сценария в KWin):

```sh
QT_QPA_PLATFORM=offscreen QT_FORCE_STDERR_LOGGING=1 /usr/lib/qt6/bin/qml tests/qt-smoke.qml
# При уже запущенном npm run dev:
QT_QPA_PLATFORM=offscreen QT_FORCE_STDERR_LOGGING=1 QT_QUICK_BACKEND=software /usr/lib/qt6/bin/qml tests/browser-smoke.qml
```
